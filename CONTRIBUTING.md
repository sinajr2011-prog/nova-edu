# Contributing to Nova-Edu

Thank you for your interest in contributing.

## High-Impact Ways to Help

1. **Clean educational data**  
   High-quality textbook extracts or Konkur solutions in the correct schema are extremely valuable.

2. **Evaluation sets**  
   Curated hold-out questions with good reference answers.

3. **Training improvements**  
   Better recipes, hyperparameter findings, or ablation results.

4. **Agent design**  
   Ideas and prototypes for the multi-agent system.

## Development Guidelines

- Keep the main branch stable.
- Prefer small, focused pull requests.
- Document any new data processing steps.
- Use the schema defined in `data/SCHEMA.md`.

## Contact

Open an issue or reach out via GitHub.
