# Konkur Simulation Mode

## Goal
Simulate a realistic exam experience with timing, scoring, and detailed analytics.

## Features
- Timed sessions (full or sectional)
- Mix of real-style questions
- Automatic scoring
- Detailed performance report:
  - Accuracy by topic
  - Time spent per question
  - Common mistake patterns
  - Recommended study plan after the test

## Flow
1. Student selects subject / duration
2. Nova generates or selects a balanced question set
3. Student answers under time pressure
4. After submission → full analysis + personalized recommendations
