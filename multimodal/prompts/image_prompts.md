# Educational Image Prompt Templates

## Core Principles

- Clarity over beauty
- Pedagogical usefulness first
- Clean, simple, textbook-like style preferred for diagrams
- Avoid unnecessary decorative elements that distract from learning

## Template Categories

### 1. Concept Diagram
```
Clean educational diagram of [concept], textbook style, white background, 
clear labels in Persian, simple and precise, high clarity, no decorative clutter
```

### 2. Geometry Figure
```
Precise geometric figure of [description], clean line art, labeled angles and sides in Persian, 
white background, textbook quality, accurate proportions
```

### 3. Step-by-step Illustration
```
Step-by-step visual explanation of [problem/concept], numbered stages, 
clean educational style, clear Persian labels, white or light background
```

### 4. Set / Venn Diagram
```
Clean Venn diagram showing [sets description], labeled in Persian, 
simple colors, textbook style, high clarity, white background
```

### 5. Process / Cycle
```
Educational process diagram of [process], sequential arrows, 
clear Persian labels, clean modern textbook style
```

## Negative Prompt Suggestions
```
blurry, low quality, watermark, text errors, cluttered, decorative, 
futuristic, cinematic lighting, 3d render, photorealistic (when not needed)
```
