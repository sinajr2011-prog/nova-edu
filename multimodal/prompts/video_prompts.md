# Educational Video Prompt Templates

## Core Principles

- Short and focused (preferably 8–20 seconds for concept clips)
- One clear idea per video
- Smooth, easy-to-follow motion
- Prefer clean educational animation style over cinematic

## Template Categories

### 1. Concept Animation
```
Short clean educational animation explaining [concept], 
simple motion, clear visual hierarchy, textbook style, 
smooth camera, high clarity, no text overload
```

### 2. Step-by-step Solution
```
Step-by-step animated solution of [problem], 
each step appears clearly, clean educational style, 
smooth transitions, easy to follow
```

### 3. Process Visualization
```
Educational animation of [process], sequential stages, 
clear visual flow, simple and precise, high pedagogical value
```

### 4. Geometric Transformation
```
Clean animation showing [geometric transformation], 
precise lines, smooth motion, labeled elements, textbook quality
```

## Style Keywords (useful)
- clean educational animation
- textbook style
- simple and clear
- smooth motion
- high clarity
- minimal distractions
